# COBRA

<div style="display:flex; align-items:center; gap:1.5rem; flex-wrap:wrap;">
	<img src="logo.png" alt="COBRA logo" width="300"/>
	<p style="margin:0; flex:1; min-width:240px;">COBRA (Circuit-Level Open-Source Based RFIC AI-Assisted Optimizer) is an open-source framework designed to optimize RF integrated circuit (RFIC) design using AI-assisted techniques. It uses surrogate models generated by ORCA to quickly predict single geometries, and integrates them into a circuit which can be simulated using a SPICE simulator. The output of this simulation is then used to optimize the model / netlist input parameters to meet the desired performance metrics.</p>
